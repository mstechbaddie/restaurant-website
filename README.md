# 🍽️ Pink Spoon Restaurant

A modern and responsive restaurant landing page built with **Next.js**, **React**, and **Tailwind CSS**.

## 🌐 Live Demo

https://restaurant-website-jade-zeta.vercel.app/

## ✨ Features

- Responsive Design
- Beautiful Hero Section
- Food Menu
- Reservation Section
- Contact Section
- Modern UI

## 🛠️ Built With

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel

## 🚀 Getting Started

```bash
git clone https://github.com/mstechbaddie/restaurant-website.git
```

```bash
npm install
```

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
